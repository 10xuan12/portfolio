# Portfolio+ 前端專案

這是一個作品集展示平台的前端版本，專為學生、企業和管理員三種使用者角色設計。

## 📁 專案結構

```
frontend/
├── index.html              # 主要首頁
├── login.html              # 登入頁面
├── register.html           # 註冊頁面
├── css/
│   └── app.css            # 主要樣式檔案
├── js/
│   └── app.js             # 主要 JavaScript 檔案
├── student/
│   └── dashboard.html     # 學生儀表板
├── enterprise/
│   └── dashboard.html     # 企業儀表板
├── admin/
│   └── dashboard.html     # 管理員儀表板
└── README.md              # 專案說明文件
```

## 🚀 快速開始

### 1. 開啟專案
直接在瀏覽器中開啟 `index.html` 即可開始使用。

### 2. 測試不同角色
- **學生**: 點擊首頁的「學生入口」或註冊時選擇學生角色
- **企業**: 點擊首頁的「企業入口」或註冊時選擇企業角色  
- **管理員**: 點擊首頁的「管理員入口」或註冊時選擇管理員角色

### 3. 登入測試
使用以下假資料進行測試：
- 電子郵件: `test@example.com`
- 密碼: `password123`

## 🔌 API 整合準備

專案已準備好與後端 API 整合：

### 認證 API
```javascript
// 登入
POST /api/auth/login
{
    "role": "student|enterprise|admin",
    "email": "user@example.com",
    "password": "password123"
}

// 註冊
POST /api/auth/register
{
    "role": "student|enterprise|admin",
    "name": "使用者姓名",
    "email": "user@example.com",
    "password": "password123",
    // 其他角色特定欄位...
}
```

### 資料 API
```javascript
// 取得學生儀表板資料
GET /api/student/dashboard

// 取得企業儀表板資料
GET /api/enterprise/dashboard

// 取得管理員儀表板資料
GET /api/admin/dashboard

// 取得作品列表
GET /api/portfolios

// 上傳作品
POST /api/portfolios
```
