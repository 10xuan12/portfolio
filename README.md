# Portfolio+ - 專業作品集展示平台

> **讓作品說話，讓才華發光** ✨

Portfolio+ 是一個革命性的作品集展示平台，專為學生、企業和管理員設計。我們打破傳統履歷制式模板，強調**作品本身即履歷**，以視覺化展示為主，特別適合設計、數位、實作類學生。

## 🌟 為什麼選擇 Portfolio+？

### 對學生的幫助
- **🎨 視覺化展示**：用作品說話，讓才華被看見
- **📈 成長追蹤**：作品時光機記錄學習歷程
- **🏆 成就激勵**：自動化徽章系統激發創作動力
- **🎯 智能分析**：技能雷達圖幫助了解自身優勢
- **💼 求職助力**：自動生成專業履歷

### 對企業的幫助
- **🔍 精準搜尋**：智能推薦系統快速找到合適人才
- **⚖️ 高效對比**：作品對比工具提升篩選效率
- **📊 數據洞察**：詳細分析報告支持決策
- **🎯 精準媒合**：基於技能和作品的智能匹配


## 🚀 三大核心功能

### 🎯 作品技能雷達圖
- **智能分析**：自動分析學生作品內容，識別技能關鍵字
- **視覺化展示**：雷達圖形式直觀展示技能分佈與強弱項
- **成長追蹤**：記錄技能發展歷程，幫助學生了解自身優勢
- **建議推薦**：基於技能分析提供學習建議和改進方向
- **企業洞察**：讓企業快速了解學生技能結構，提升招聘效率

### ⏰ 作品時光機
- **時間軸展示**：按時間順序展示作品演進歷程
- **成長軌跡**：追蹤學習和創作歷程，展現進步軌跡
- **里程碑標記**：重要作品和成就節點的可視化展示
- **進步可視化**：讓企業看到學生的成長潛力和學習能力
- **故事性呈現**：將作品集轉化為成長故事，更具說服力

### 🔍 分析工具
- **作品對比工具**：企業可同時對比多個學生作品，快速比較技能、風格與品質
- **智能推薦系統**：基於關鍵字匹配的人才推薦，提升媒合效率
- **熱門標籤系統**：自動標記「熱門」、「趨勢」、「新作」等，提升作品曝光度
- **人才搜尋引擎**：多維度篩選和搜尋功能，精準找到合適人才

## 🎯 Demo 重點說明

### 目前可 Demo 的學生端介面

#### 1. 學生儀表板 (`frontend/student/dashboard.html`)
- **快速操作區塊**：上傳新作品、編輯作品集、更新個人資料、生成履歷
- **我的作品展示**：網格式展示已上傳的作品，支援 3D 翻轉效果
- **技能分析區塊**：
  - 技能標籤雲：視覺化展示技能分佈
  - 技能雷達圖：分析技能強弱項
  - 作品時光機：追蹤學習成長歷程
- **側邊欄功能**：
  - 最近活動記錄
  - 徽章成就系統（創作者、曝光中、人氣創作者等）
  - 企業互動統計
  - 成就通知系統

#### 2. 作品上傳介面 (`frontend/student/upload.html`)
- **三步驟上傳流程**：
  - 步驟1：基本資訊（標題、學群分類、描述）
  - 步驟2：檔案上傳（支援多格式，最大50MB）
  - 步驟3：預覽確認（可選擇發布或儲存草稿）
- **支援格式**：圖片、影片、音訊、PDF、壓縮檔、3D模型等
- **智能標籤系統**：自動生成相關標籤，幫助企業更容易找到作品
- **即時預覽**：上傳過程中即時預覽效果

#### 3. 個人資料管理 (`frontend/student/profile.html`)
- **頭像上傳**：支援個人頭像更換
- **基本資料編輯**：姓名、科系、年級、學生編號
- **統計資訊**：作品數量、瀏覽次數、互動數據

#### 4. 其他學生端功能
- **作品集管理** (`portfolio.html`)：編輯和管理已上傳的作品，支援批量操作
- **履歷生成** (`resume.html`)：基於作品自動生成專業履歷，支援多種模板
- **通知系統** (`notifications.html`)：接收企業互動通知，支援即時推送
- **作品搜尋** (`search.html`)：瀏覽其他學生的作品，支援熱門關鍵字推薦
- **技能分析** (`skill-radar-demo.html`)：詳細的技能雷達圖分析
- **作品時光機** (`portfolio-timeline-demo.html`)：時間軸展示作品演進歷程

## 🏆 徽章系統運作

### 自動授予機制
- **創作者**：上傳3件作品解鎖
- **曝光中**：作品被企業瀏覽10次解鎖  
- **人氣創作者**：被留言超過5次解鎖
- **資深創作者**：註冊超過30天解鎖
- **熱門作品**：作品獲得50個讚解鎖
- **互動達人**：作品被評論20次解鎖

### 徽章展示與通知
- 學生儀表板側邊欄顯示已獲得徽章
- 作品頁面展示創作者徽章
- 成就通知系統即時提醒新獲得的徽章
- 激勵學生持續創作和互動
