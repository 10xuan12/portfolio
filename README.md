# Portfolio+ - 專業作品集展示平台

Portfolio+ 是一個專為學生、企業和管理員設計的作品集展示平台。打破傳統履歷制式模板，強調作品本身即履歷，視覺化展示為主，特別適合設計、數位、實作類學生。

## 🚀 平台特色

### 1. 以作品為核心
- **打破傳統履歷制式模板**：多數平台（104、CakeResume）以「制式履歷表」為主，作品僅是附加檔案
- **作品即履歷**：強調作品本身即履歷，視覺化展示為主
- **適合設計、數位、實作類學生**：特別針對創意產業和技術領域優化

### 2. 更簡單上手的作品上傳與管理介面
- **一頁式管理**：提供學生一頁式、可分類、支援多格式的作品管理與上傳功能
- **多媒體支援**：支援圖片、文字檔、程式碼等多種格式
- **操作直觀**：設定步驟簡化，無法分類多個作品或用多媒體呈現

### 3. 智能推薦機制
- **關鍵字比對**：抓作品簡介裡的關鍵字比對，主動推薦作品給企業
- **主動推薦**：靠關鍵字或人工投遞，提高媒合效率

## 👥 三種用戶角色

### 學生端
- ✅ 上傳作品集（圖片、文字檔、程式碼）

### 企業端

- ✅ 聯絡作者
- ✅ 收藏作品

### 管理員端
- ✅ 管理作品
- ✅ 管理評價
- ✅ 系統設定
- ✅ 用戶管理
- ✅ 數據分析

## 🏆 徽章系統

鼓勵學生上傳、編輯、互動：

- **創作者**：上傳3件作品解鎖
- **曝光中**：作品被企業瀏覽10次解鎖
- **人氣創作者**：被留言超過5次解鎖
- **資深創作者**：註冊超過30天解鎖
- **熱門作品**：作品獲得50個讚解鎖
- **互動達人**：作品被評論20次解鎖

- **HTML5**：語義化標記

### 安全特性
- **密碼雜湊**：使用 bcrypt 演算法
- **SQL 注入防護**：參數化查詢
- **XSS 防護**：輸出轉義
- **CSRF 保護**：跨站請求偽造防護
- **輸入驗證**：完整的資料驗證

## 🚀 快速開始

### 系統需求
- PHP 8.0 或更高版本
- MySQL 8.0 或更高版本
- Apache/Nginx 網頁伺服器
- 支援 PHP 的 Web 環境

### 安裝步驟

1. **克隆專案**
   ```bash
   git clone https://github.com/your-username/portfolio-plus.git
   cd portfolio-plus
   ```

2. **設定資料庫**
   - 創建 MySQL 資料庫
   - 匯入 `sql/portfolio_plus.sql` 檔案

3. **配置設定**
   - 複製 `config/config.example.php` 為 `config/config.php`
   - 修改資料庫連線設定

4. **設定權限**
   ```bash
   chmod 755 uploads/
   chmod 755 images/
   ```

5. **啟動應用程式**
   - 將專案部署到 Web 伺服器
   - 訪問首頁開始使用
