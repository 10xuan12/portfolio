# Portfolio+ - 專業作品集展示平台

Portfolio+ 是一個專為學生、企業和管理員設計的作品集展示平台。打破傳統履歷制式模板，強調**作品本身即履歷**，以視覺化展示為主，特別適合設計、數位、實作類學生。

## 🎯 Demo 重點說明

### 目前可 Demo 的學生端介面

#### 1. 學生儀表板 (`frontend/student/dashboard.html`)
- **快速操作區塊**：上傳新作品、編輯作品集、更新個人資料、生成履歷
- **我的作品展示**：網格式展示已上傳的作品
- **側邊欄功能**：
  - 最近活動記錄
  - 徽章成就系統（創作者、曝光中、人氣創作者等）
  - 企業互動統計

#### 2. 作品上傳介面 (`frontend/student/upload.html`)
- **三步驟上傳流程**：
  - 步驟1：基本資訊（標題、學群分類、描述）
  - 步驟2：檔案上傳（支援多格式，最大50MB）
  - 步驟3：預覽確認（可選擇發布或儲存草稿）
- **支援格式**：圖片、影片、音訊、PDF、壓縮檔、3D模型等
- **標籤系統**：幫助企業更容易找到作品

#### 3. 個人資料管理 (`frontend/student/profile.html`)
- **頭像上傳**：支援個人頭像更換
- **基本資料編輯**：姓名、科系、年級、學生編號
- **統計資訊**：作品數量、瀏覽次數、互動數據

#### 4. 其他學生端功能
- **作品集管理** (`portfolio.html`)：編輯和管理已上傳的作品
- **履歷生成** (`resume.html`)：基於作品自動生成履歷
- **通知系統** (`notifications.html`)：接收企業互動通知
- **訊息中心** (`messages.html`)：與企業的溝通管道
- **作品搜尋** (`search.html`)：瀏覽其他學生的作品

### 目前可 Demo 的企業端介面

#### 1. 企業儀表板 (`frontend/enterprise/dashboard.html`)
- **快速操作區塊**：瀏覽作品、發布職缺、企業資料、通知、搜尋人才

- **側邊欄功能**：

## 🔄 系統運作流程

### 1. 學生端完整流程

```
註冊/登入 → 完善個人資料 → 上傳作品 → 獲得徽章 → 與企業互動
```

**詳細步驟：**
1. **註冊登入**：學生使用學號或email註冊，選擇「學生」角色
2. **完善資料**：填寫基本資訊（姓名、科系、年級等）
3. **上傳作品**：
   - 填寫作品基本資訊（標題、學群分類、描述）
   - 上傳多媒體檔案（支援圖片、影片、程式碼等）
   - 設定標籤提高被發現機率
   - 選擇發布或儲存草稿
4. **自動獲得徽章**：系統根據上傳作品數量、瀏覽次數等自動授予徽章
5. **接收企業互動**：企業瀏覽、留言、收藏作品時會收到通知

### 2. 企業端完整流程

```
註冊/登入 → 完善企業資料 → 搜尋人才 → 瀏覽作品 → 聯絡學生
```

**詳細步驟：**
1. **註冊登入**：企業使用公司email註冊，選擇「企業」角色
2. **完善資料**：填寫公司資訊（公司名稱、聯絡人等）
3. **搜尋人才**：
   - 使用關鍵字搜尋
   - 依技能、科系、年級篩選
   - 瀏覽推薦人才
4. **瀏覽作品**：
   - 查看學生作品集
   - 按相關度、時間、熱度排序
   - 收藏感興趣的作品
5. **聯絡學生**：透過平台內建訊息系統與學生溝通

### 3. 智能推薦機制

**關鍵字匹配系統：**
- 企業在儀表板設定搜尋條件
- 系統自動匹配相關學生作品
- 推薦區塊顯示最相關的人才
- 支援即時刷新推薦結果

**匹配邏輯：**
- 作品標題和描述中的關鍵字
- 學生科系和年級
- 作品標籤和技能標記
- 瀏覽和互動歷史

## 🏆 徽章系統運作

### 自動授予機制
- **創作者**：上傳3件作品解鎖
- **曝光中**：作品被企業瀏覽10次解鎖  
- **人氣創作者**：被留言超過5次解鎖
- **資深創作者**：註冊超過30天解鎖
- **熱門作品**：作品獲得50個讚解鎖
- **互動達人**：作品被評論20次解鎖

### 徽章展示
- 學生儀表板側邊欄顯示已獲得徽章
- 作品頁面展示創作者徽章
- 激勵學生持續創作和互動

## 🛠️ 技術架構

### 後端技術
- **PHP 8.0+**：主要程式語言，處理業務邏輯
- **MySQL 8.0+**：資料庫儲存
- **PDO**：安全的資料庫連接
- **JWT Token**：用戶認證和授權
- **Session**：用戶會話管理

### 前端技術
- **HTML5 + CSS3**：響應式介面設計
- **JavaScript ES6+**：互動功能和 API 調用
- **Font Awesome**：圖標庫
- **Bootstrap Icons**：額外圖標支援

### API 架構
- **RESTful API**：標準化的 API 設計
- **JSON 格式**：前後端資料交換
- **角色權限控制**：學生、企業、管理員分權
- **檔案上傳支援**：多格式檔案處理
